# Анализ A/B-теста для алгоритмов рекомендаций

**Данный учебный проект выполнен в рамках программы профессиональной переподготовки.**

**Стек технологий**: Python (pandas, matplotlib, statsmodels)

**Ключевые компетенции:** EDA, A/B-тестирование, проверка статистических гипотез, Z-тест, анализ результатов и мониторинг

## Описание проекта

Этот проект воспроизводит рабочий процесс аналитика данных в компании, разрабатывающей развлекательное приложение.
Команда разработки рекомендательных систем создала новый алгоритм, который, по их гипотезе, подбирает более интересный контент индивидуально для каждого пользователя. Цель данного исследования — определить параметры для проведения A/B-теста с целью проверки этой гипотезы и проанализировать полученные результаты.

## Основные этапы работы
- **Исследовательский анализ данных (EDA):** Изучение исходного датасета и проверка распределений.
- **Проектирование A/B-теста:** Расчёт необходимого размера выборки и длительности эксперимента.
- **Статистическая оценка:** Проведение тестов и проверка метрик.
- **Результаты и рекомендации:** Оценка p-value, проверка статистической значимости и формирование бизнес-выводов на основе данных.

## Выводы
Минимально необходимый размер выборки для эксперимента составлял 41 040 пользователей на группу при расчётной длительности в 9 дней. Фактически тест продолжался 20 дней, в течение которых было собрано 100 005 записей о сессиях (приблизительно по 15 000 уникальных пользователей в каждой группе). Двухвыборочный Z-тест показал значение p-value = 0.58, что превышает выбранный уровень значимости. Это не позволяет отвергнуть нулевую гипотезу и указывает на отсутствие статистически значимых доказательств того, что новый алгоритм улучшил показатели успешности первых сессий. Таким образом, рекомендуется не раскатывать алгоритм на продакшен, так как изменения не продемонстрировали измеримого положительного влияния на вовлечённость пользователей, способного оправдать затраты на внедрение и поддержку.
